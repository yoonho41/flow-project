파일 확장자 차단 과제(김윤호) : 과제 고려사항

SpringBoot + MySQL

채용공고의 자격요건을 참고하여 최대한 연관성 있는 기술 스택으로 구성했습니다.


권한 기반 접근 제어(간단 로그인)

회원가입 기능 없이 최소한의 로그인 기능만 구현했습니다.

관리자만 확장자 차단 기능에 접근할 수 있도록 권한을 분리했습니다.

관리자 ID/PW : admin / admin

일반 사용자 ID/PW : user / user


요청 중 UI 비활성화

고정 확장자 체크박스 클릭 및 커스텀 확장자 "추가" 요청 처리 중에는 입력을 임시 비활성화하여 오류를 방지했습니다.


커스텀 확장자 중복 등록 방지

커스텀 확장자를 이미 등록한 상태에서 동일 확장자를 다시 추가하면 alert로 안내하고 등록을 제한했습니다.


커스텀 입력을 통한 고정 확장자 등록

커스텀 입력에서 고정 확장자 목록(bat, cmd 등)을 입력하면 체크박스 클릭과 동일한 동작을 수행하도록 처리했습니다.

이미 고정 확장자가 체크된 경우에는 중복 등록으로 판단하여 alert로 안내했습니다.

커스텀 확장자 등록 한도에 도달한 상태라도 고정 확장자 등록은 가능하도록 분리했습니다.


파일 업로드 화면 구현

실제 업로드(서버 저장)는 구현하지 않았습니다.

파일 선택 시 DB 차단 확장자에 해당하면 파일 등록이 차단되는 것을 확인할 수 있습니다.
